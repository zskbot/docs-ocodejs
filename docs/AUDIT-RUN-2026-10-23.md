- The runner created the text corpus in temporary storage to scan and hash files, but only the metadata artifact was uploaded. The raw corpus was not published.

- Review upstream licenses and attribution before redistributing full source documents. Prefer source-linked summaries and deduplication over blindly committing the full corpus.
- No source repository was modified; no database writes, secrets changes, merge or production deployment occurred.
