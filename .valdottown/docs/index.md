Val Town lets you—and your AI agent—write and run JavaScript, always deployed in
100ms. You can make websites, APIs, MCP servers, crons, Slack bots, email
automations, webhook handlers, and more.

## AI

Connect Claude, ChatGPT, Claude Code, Codex, or Cursor to Val Town with the
[Val Town plugin](/guides/prompting/plugin). Choose your app for its setup guide,
connect your Val Town account, and check the connection in a new chat.

[Townie](/guides/prompting/townie) is our resident coding robot.
[Learn more about AI in Val Town](/guides/prompting).

## Learn

If you’re new here and want to learn fundamentals the old fashioned way, read:
[What is a val?](/vals) You can run code via HTTP, email, and cron. We have
SQLite, blob storage, environment variables, version control, and plenty more.
